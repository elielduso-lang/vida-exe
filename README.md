# VIDA.EXE — V0.2

**Menos simulador formal. Más decisiones sobre una vida absurda, impredecible y rejugable.**

De los 18 a los 80. Situaciones rápidas, riesgos reales, logros ocultos.

## Novedades V0.2

- Decisiones de alto riesgo (SEGURO / ARRIESGADO / DEMENTE)
- Probabilidades según stats, personalidad y flags
- Eventos legendarios (incluso 1–3%)
- Logros persistentes (algunos ocultos)
- Callbacks a lo largo de la vida
- Final con relato + rareza

## Local

```bash
npm install
npm run dev
```
